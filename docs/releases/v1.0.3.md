# v1.0.3 版本说明

项目交付版本为 `1.0.3`。通道记忆与表达采用此前的 V2 设计，固定上游组件保持 `0.1.0-rc.5`，原来源和 MIT 许可见 [NOTICE](../../NOTICE)。本分支待合并，发布标签另行创建。

## 变更

- 新增通道记忆及来源回执，支持记录、纠正、遗忘和临时无记忆会话。自动提炼默认关闭，使用单独配置的无工具 HTTP 适配器。
- 新增动态表达、短期情绪和本机控制页，保留已有会话身份快照。控制页访问文件不可写时，微信消息和记忆功能仍可运行。
- 支持查询包括闲置在内的本机会话名称与 ID、查询活动、创建项目会话和向授权目标委派。按本轮明确任务执行，支持催办与取消排队，结果回到发起通道。
- Windows 登录自启动核验固定构建和账号范围，运行端与启动配置使用同一已验证构建。

## 验证

2026-11-23 类型检查、独立复审及 736 项测试通过。本机已通过原计划任务启动同一功能构建，核对两个通道、控制页及旧资料保留。真实微信委派、Windows 整机重启和真实自动提炼未纳入本轮验收。

见 [使用手册](../user-guide.md)、[委派说明](../session-delegation.md) 与 [验收说明](../acceptance.md)。
