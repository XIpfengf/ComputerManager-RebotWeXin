# V1.0.2 发布说明

项目版本为 `1.0.2`，标签 `v1.0.2` 指向 develop 合并到 main 的发布提交。固定上游组件保持 `0.1.0-rc.5`，MIT 许可及来源不变。

## 本次修复

- 新增授权 Desktop 会话的只读进度查询，权限不足时直接说明；支持按 ID 单独授予只读访问，不授予任务委派权限。
- 大型会话查询改用元数据与有界文字窗口，避开整轮工具记录和图片导致的响应超限；保留文字时间及窗口不完整提示。
- 区分响应超限、连接与来源权限错误，不再笼统提示用户新建微信会话。
- 内部技能、规则文档引用只保留名称，不再误当作附件；普通授权文件交付规则保留。
- 对齐使用手册、专题、验收及版本记录，私有权限配置与原始诊断证据继续忽略。

## 验证与边界

类型检查及 614 项测试通过，0 失败、0 跳过，包含构建。真实大型目标只读查询已通过；用户授权加载后两个微信通道正常，查询来源权限检查通过，既有委派队列保留。未打断目标执行，未重启 Windows。

本轮微信体验仍待用户验收；不能将独立只读验证等同于完整手机链路验收。只读观察连接的 notLoaded、旧进度和窗口存在均不证明目标停止或执行。按 ID 配置的权限不自动包含未来新会话，其他微信专属会话保持隔离。跨会话委派异步附件、完整软件/网络矩阵、Windows 重启登录等限制仍保留。

详情见 [验收说明](../acceptance.md)、[使用手册](../user-guide.md) 和 [委派说明](../session-delegation.md)。发布不含真实配置、凭据、数据库、聊天或原始验收材料，不修改旧标签。
