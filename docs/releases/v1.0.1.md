# V1.0.1 发布说明

项目：ComputerManager-RebotWeXin。项目版本为 `1.0.1`，发布标签为 `v1.0.1`，指向 develop 合并到 main 的实际发布提交。固定上游组件仍为 `0.1.0-rc.5`，来源及 MIT 许可不变，见 [NOTICE](../../NOTICE)。

## 本次更新

- 修复 Desktop 更新后工具执行器缺失：选择完整运行时，空闲时刷新执行连接，保护正在运行的任务。
- 工具配置变化后刷新连接，恢复微信执行会话的窗口读取、输入和键盘操作能力。
- 支持向 Desktop 已有会话委派任务：连接发现、名称定位、通道授权、持久化排队、精确结果关联和全文回传。
- 未加载会话在确认回合终结后允许投递；忙碌目标保持排队，结果未知时不自动重发。
- “告诉它……”可以接续同通道同来源会话近期唯一目标；有歧义时保留任务并询问目标，确认请求持久化、10 分钟有效，否定回复不会变成确认。
- 同步使用手册、专题和验收说明，明确文档职责；脱敏真实路径与会话编号，完善配置、凭据和数据库忽略规则。

## 验证与限制

类型检查及 606 项自动化测试通过，0 失败、0 跳过；包含构建、权限隔离、忙碌保护、断线去重、确认恢复与否定保护。已有能力包含隔离实机验证和用户微信确认，详见 [验收说明](../acceptance.md)。指代接续修复已授权加载，两个微信通道恢复正常，权限边界检查通过；本轮指代体验仍待用户微信验收。

跨会话委派当前回传最终文字，目标文件链接尚不自动作为异步附件回传；目标审批仍遵循自身规则。Windows 重启登录、长期归档调度、所有软件、鼠标操作、媒体与网络故障组合未被宣称全部实机验收。多微信通道不是 Windows 文件系统沙箱。

发布只含源码、测试及脱敏文档，不包含真实配置、凭据、Cookie、数据库、聊天或原始验收材料。不修改已有 `v1.0.0` 标签及其发布内容。部署和命令见 [使用手册](../user-guide.md)，目录与私有资料保留见 [目录说明](../directory-layout.md)。
