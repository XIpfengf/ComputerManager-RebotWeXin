# V1.0.0 发布说明

项目：ComputerManager-RebotWeXin。版本值为根目录 VERSION 中的 `1.0.0`，发布标签为 `v1.0.0`，标签定位合并到 main 的发布提交。部署与指令见 [使用手册](../user-guide.md)。

## 功能

- 普通微信与本机 Codex 通信，一个中间件实例支持多个独立微信通道。
- 每通道配置人设、称呼、语气、角色力度，以及新会话模型、推理强度和默认项目。
- 新会话固定身份快照，支持自然聊天、授权历史检索、浏览器查证与本机工具任务。
- 当前会话持续保持，服务恢复保留选择，后台通知不会自动切换会话。
- 长回复完整分片、文件链接转真实附件、跨盘文件复制到任务工作目录后发送。
- 任务状态、取消、上下文压缩、审批、项目与会话导航、Guard冲突协调及当前用户登录自启动。
- 历史归档支持预览、一次确认、固定保留、恢复与未知结果对账；自动归档默认关闭，不永久删除历史或用户文件。

## 验证与限制

源码类型检查和558项自动化回归通过；真实隔离会话验证身份、模型/强度、进程恢复、历史检索、浏览器查证及归档恢复。普通微信、双微信、长回复和附件已有实机反馈。具体结果见 [验收说明](../acceptance.md)。

Windows重启/注销触发、真实跨30天调度、完整人设梯度、所有软件/媒体及网络边界未被宣称全部实机验收。软件/API能力取决于本机工具和授权；多微信不构成操作系统沙箱。归档不等于释放历史占用。发布不包含凭据、真实人设、数据库、原始聊天或本机备份。

本项目版本与 vendor 中第三方组件的包版本分别维护；保留固定上游版本0.1.0-rc.5、来源和MIT声明，详见 [NOTICE](../../NOTICE)。
