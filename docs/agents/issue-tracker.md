# 本地任务跟踪约定

用户已明确选择只保留本地文件，不使用 GitHub Issues 或其他远端任务系统。本文件记录当前已确认的选择，不触发其他工程技能初始化或修改本机代理规则。

- V2 本地工单放在 `.scratch/v2-persona-memory/`，随本机工作区维护。可共享的契约和验收分别见 [V2 规格](../v2.0.0-persona-memory-spec.md) 与 [验收说明](../acceptance.md)。
- 每个 ticket 独立保存于该功能的 `issues` 目录，按两位编号命名，前置依赖写在 `Blocked by` 中。
- 新准备好的 ticket 使用 `ready-for-agent`；执行和完成可使用 `in-progress`、`done`。依赖未完成的 ticket 即使状态为准备好也不可开工。
- “发布到任务跟踪器”在本项目本轮工作中指写本地文件；不意味着创建远端 issue、提交、推送或发布产品。
- 规格、任务、实现证据分别维护；前置未通过时不跳到实机验证，不自动关闭或修改上层规格。

当前不配置其他 triage 角色，不引入额外审核或远端工作流。
