## 日常使用

在对应微信通道单独发送纯文字：

| 命令 | 作用 |
| --- | --- |
| `memory panel` | 返回本通道本机控制页链接，在运行 Bridge 的电脑浏览器打开 |
| `memory explain` | 查看当前会话最近的表达策略、模型接收回执、记忆来源与选择理由 |
| `memory recall 你怎么看这个安排` | 只做本地记忆检索，不启动模型或执行任务 |
| `memory preview 直接给结果，取消执行了吗` | 预览表达策略，不生成模型回答、不写入情绪事件 |
| `memory reply status` | 查看表达设置与状态 |
| `memory reply set warmth 4` | 温暖甜度，范围 0–5 |
| `memory reply set humor 3` | 幽默程度，范围 0–5 |
| `memory reply set tsundere 2` | 傲娇程度，范围 0–5 |
| `memory reply set emoji 1` | 表情程度，范围 0–5 |
| `memory reply set initiative 1` | 主动追问程度，范围 0–5 |
| `memory reply set verbosity concise` | 回复长度；还支持 `normal`、`detailed` |
| `memory reply set humor inherit` | 继承当前会话人设；其他表达项也支持 `inherit` |
| `memory reply enable` / `memory reply disable` | 开关每轮动态表达提示，不修改身份快照 |
| `memory mood enable` / `memory mood disable` | 独立开关模拟情绪记录及表达调节 |
| `memory mood reset` | 恢复本通道情绪基线，保留身份和长期记忆 |
| `memory recall set time 2` | 排序权重 0–5；还支持 `relevance`、`explicit` |

记忆事实继续使用原来的 `memory remember`、`memory correct`、`memory forget`。例如：

```text
memory remember 我希望你回复甜一些，语气幽默一些
```

“你怎么看、你的想法”等意见交流可召回此偏好。“太腻了，收一点”使本轮收敛表达，不将一次要求写成永久偏好。真实操作、失败、取消、审批及“直接给结果”场景收敛表演并准确说明状态；概念讲解、方案讨论和分享工作可以保留原有语感。身份名字、背景及旧快照保持。

明确设为 0 不会被旧偏好或情绪重新调高。默认继承既有人设的 0–5 档位，控制页分别展示继承值和本轮实际策略。身份力度为 0 时保持中性表达。

## 来源、状态与关闭

- 记忆先核验认证账号、原始来源、当前归属、完整性和有效状态，再做中文主题/词语匹配、时间排序、去重和预算选择。候选池最多 1000 条，注入最多 12 条且不超过 4096 字节；不扫描聊天全文、不使用其他通道兜底。
- 当前问题优先使用有效纠正；明确询问“最早”时允许返回带 `superseded` 和有效期的旧版本。已遗忘内容不参加历史召回，也不经旧回执重新展示。
- 排序分数不是事实可靠性的概率；权重不能改变来源资格、遗忘状态或纠正优先级。
- 情绪是独立模拟状态：平静、开心、好奇、关切、疲惫。按本通道合格原话的有限规则更新，保存来源坐标、哈希和事件类别，不复制完整聊天。无法可靠分类的材料不产生事件。
- 情绪随时间恢复，切换有余量和保持时间，重复消息不重复记账。事件、状态、设置及回执按账号隔离；无记忆临时会话不参加动态表达或情绪。
- 来源不明、外部引用、混合资料、明显引文和长材料不用于情绪记账。短期情绪不自动写成长期用户人格事实。
- `memory disable` 停止事实记忆采集、提炼和注入。动态表达和模拟情绪有独立开关；如也要停止情绪记账，另发 `memory mood disable`。

规则在本机计算，无新增后台模型调用。真实聊天的提示和记忆仍占模型上下文，费用随正常请求计算，不保证零 token 成本。自动事实提炼继续使用单独的无工具 HTTP 后端和开关；本增量不配置密钥、不自动开启提炼或历史回填。

## 控制页与送达回执

控制页随 Bridge 启停，只监听 `127.0.0.1`，使用随机端口和每通道独立访问链接。手机的 `127.0.0.1` 不指向运行 Bridge 的电脑，链接应在该电脑打开。服务重启后重新发送 `memory panel` 获取链接。

页面可修改表达和情绪开关、强度、长度、召回权重，并预览策略。预览没有模型生成环节。记忆展示包含来源会话、消息坐标和排序理由；不把工具资料导入为自身记忆。

每个链接固定对应一个通道，接口不接受改账号、身份、来源或任意路径。设置有修订校验，过期页面须刷新后保存。拒绝跨源、错误 Host、非 JSON 和超大请求，不加载外部脚本或字体。访问链接保存在本机私有文件，不进入公开日志或仓库。

策略通过官方 `turn/start.additionalContext` 的 `application` 项送达，记忆继续是 `untrusted` 数据。用户原文不改写，旧身份快照不重编译。“策略已准备”和“已提交模型”分开记录，只有收到原生回合接收结果后才标记后者。

## 实现与验收

核心入口：[通道表达](../vendor/codex-ilink/src/interaction/conversation.ts)、[本机接口](../vendor/codex-ilink/src/interaction/panel.ts)、[中文召回](../vendor/codex-ilink/src/memory/retrieval.ts)。集成原 Bridge 即时和排队消息路径。固定部署配置的 `interactionEnabled` 只作用于核验后的账号范围，首次初始化时启用；用户后续主动关闭会跨重启保留。

访问文件不可写时，控制页暂不可用，微信消息和记忆功能仍可运行。已有控制页的链接仍有效，新通道的链接会在访问文件恢复可写后生成。

2026-11-03 类型检查及 713 项完整回归通过。新增测试覆盖意见偏好、时间/纠正/遗忘、最大权重不串通道、实际即时/排队输入、情绪幂等/恢复/重置、关闭与重开、当前收敛要求、接口通道范围/过期修订/跨源与非法字段。浏览器已用合成数据操作保存和预览并核对版式。

真实部署的 PID、固定构建、两通道状态、原人设/身份/记忆保留校验和任务 XML 备份保存在被忽略的本机验收目录。本文不含真实账号、人设、聊天或访问凭据。实际语气与长期体验由真实交流评价，不拿合成测试冒充真人体验通过。

## 表达约束版本 2

按用户进一步批准的 [中文表达姿态设计](v2.0.0-expression-design.md)，已实现角色一致的多姿态、中文组织和语境变化规则。现有回复开关继续生效，无新命令，不需要 `new` 或重写身份；两个通道从下一条正常消息开始使用。

- 模型在同次生成中决定主姿态和必要的辅姿态，允许清楚讲解、有依据的分歧、轻松机锋、善意挑衅、俏皮嘴硬和保留判断；仍受各自人设、表达等级和本轮要求约束。
- “直接讲原理，简短回答，保留你的语气”保留语感并缩短内容；“直接给结果”保持直接。“别怼了，认真解释”立即停止拌嘴，本轮结束后不永久改写设置。
- 中文词序、断句、省略、反问、语气词和句长参与组织；不固定先损后夸，不每轮都追问。模拟情绪只作弱背景，不强制每轮安慰。
- `memory preview`、`memory explain` 和本机页展示允许范围、局部场景提示与送达回执，不能据此断言模型实际选择了某种姿态。旧回执保留原状，后续正常回复产生新回执。
- 类型检查与 722 项完整回归通过；23 轮真实模型调用只使用隔离合成资料，包含对照与修正，不属于生产后台作业。真实自然度和长期体验仍由日常交流检验，模型生成延迟与正常上下文费用仍存在。

已更新固定构建并通过原自启动任务重启，双通道运行及版本 2 本机接口核验通过。现有人设、旧身份快照、事实与来源、遗忘记录及设置与备份哈希一致；自动提炼仍未开启。
